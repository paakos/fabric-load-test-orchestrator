# Agent prompts

Natural-language prompts to deploy and operate the orchestrator with an AI agent. Replace the values in `<angle brackets>`.
Read [docs/agent-deployment.md](../../docs/agent-deployment.md) first (prerequisites and good practice).

In VS Code you can copy these files to `.github/prompts/` and run them from the chat as `/<file name>` (agent mode).

- [Install, with a dry run first](01-install-dry-run-first.prompt.md)
- [Install with my models already configured](02-install-with-models.prompt.md)
- [Run a test and follow it](03-run-a-test.prompt.md)
- [Analyze the results](04-analyze-results.prompt.md)
- [Deploy the Fabric App](05-deploy-the-app.prompt.md)
- [Update to a new version](06-update.prompt.md)
- [Remove](07-remove.prompt.md)
